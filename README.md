# 加油站便利店批次库存台

按批次管理加油站便利店库存的前端最小闭环（Vue 3 + Vite + TypeScript + Pinia，纯前端，数据存 localStorage）。

## 业务规则

- **五类流水**：入库 / 售出 / 退库 / 跨店调拨 / 召回，另有盘点产生的**库存调整**流水。流水只追加、不可改。
- **余额重放**：不存在可直接改写的“余额”字段，批次 × 库位余额随时由全部流水按序重放得出，刷新页面结果一致。
- **售出 FEFO**：售出时按到期日升序（同效期按先入库顺序）自动选批、自动拆批；界面给出与引擎同一逻辑的扣批预览。
- **跨店调拨**：一笔调拨成对生成 `transfer_out` / `transfer_in` 两条互相关联的流水，来源按 FEFO 扣批，目标按**相同批次号、相同效期**落账；任一端失败整笔取消。
- **召回**：召回把批次在该库位余额全额出库，此后该批次在所有店禁止售出 / 调出 / 退库回货架 / 盘盈。
- **盘点冻结**：开始盘点即冻结对应库位，期间入库/售出/退库/调拨一律拦截；差异确认后**只能生成带符号的 adjust 流水**，不允许直接改余额；库位内所有批次必须全盘。
- **整单原子性**：每笔操作都在“从已提交流水重放出的全新账本”上试算，数量/批次/库位任意一处不合法即抛错丢弃，已提交流水不会留下任何部分行。

## 目录

```
src/inventory/   领域类型、不可变流水引擎（replay / Ledger / FEFO / 追溯）、种子数据
src/stores/      Pinia store：试算-提交、冻结集合、localStorage 持久化
src/components/  操作面板、盘点面板、批次台账、流水账、批次追溯弹窗
e2e/             Playwright 端到端覆盖
```

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 类型检查 + 生产构建
npm run preview   # 预览构建产物
```

## 端到端覆盖

先 `npm run preview`（默认 4173 端口），再：

```bash
npx playwright install chromium
npm run test:e2e
```

覆盖：入库、售出 FEFO 拆批扣减、跨店调拨出入成对、盘点冻结 + 差异调整流水、召回后禁止出库、非法操作整单回滚（流水不增）、批次完整去向追溯、刷新后重放一致，以及 390px 手机视口。
